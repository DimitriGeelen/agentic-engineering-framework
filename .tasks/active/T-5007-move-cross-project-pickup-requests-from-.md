# T-5007: Move cross-project pickup requests from the sidecar to GitHub issues

## Problem Statement

Peer projects send work requests to AEF over the sidecar (`fw pickup`, peer messages). Those requests are invisible to outside contributors and to anyone not on our hosts, and they live in two places (sidecar inbox, then our task). The operator raised (2026-11-02, with T-5006) whether pickup requests should move to GitHub issues, so peers and outside contributors use one public intake. Today: 82 pickups processed, 10 rejected, 4 auto-deferred; `fw issues` already syncs GitHub issues into tasks.
