## RCA

**Symptom:** CTL-029 (`agents/audit/audit.sh`, T-2055) fires a standing WARN
("has all Agent ACs ticked but status=... — completable, not closed") on
correctly partial-complete tasks: `owner: human`, `### Agent` fully ticked,
one or more `### Human` criteria still open (`[REVIEW]` etc.) — exactly the
state CLAUDE.md §Agent/Human AC Split prescribes for a human-gated close. The
only "fix" the WARN suggests (`fw task update --status work-completed`) is a
sovereignty violation an agent must not perform. 832-Workflow-designer hit
this in their vendored copy, filed four remediation tasks against the
resulting false WARNs before finding the cause, patched their own copy, and
asked (OBS-485 / sidecar 832-T833) that the fix land upstream so their
`.vendor-divergence.yaml` entry can drop.

**Root cause:** the predicate selects only the `### Agent` sub-section and
counts ticked/unticked within it (`agents/audit/audit.sh` ~L5681-5707,
pre-fix). It never reads `owner:` from frontmatter and never looks at
`### Human` at all — so "all Agent ACs ticked" and "task is actually done" were
conflated. Those two are the same thing only when there is no Human AC gate;
CLAUDE.md's own partial-complete lifecycle (Agent ACs done, Human ACs pending,
`owner: human`, task stays in `active/`) means they routinely diverge.

**Why structurally allowed:** CTL-029 (T-2055) was written as "the active-side
mirror of CTL-028" (which checks *completed/* tasks for consistency) before the
Agent/Human AC split (T-193) and the partial-complete state were load-bearing
conventions this heavily used. The predicate was correct for the shape it was
written against and was never revisited when partial-complete became a
first-class, frequently-hit lifecycle state — nothing forced the two to be
reconciled, so the gap sat live in `agents/audit/audit.sh` until a peer
project's vendored fork hit it hard enough (four remediation tasks) to trace
it back.

**Prevention:** `tests/unit/t3444_ctl029_partial_complete.bats` pins all four
branches (owner:human+open Human AC → silent; abandoned agent-owned, all
Agent ACs ticked → fires; owner:human, all Human ACs ticked → fires;
owner:human, no `### Human` section → fires) against fixture task files, and
refuses to pass vacuously if the CTL-029 predicate is ever moved/renamed
without the test being updated (grep-and-exit-3 guard, test 1). The existing
`tests/unit/test_audit_completable_not_completed.bats` (owner:agent shapes)
stays green unchanged, confirming no regression on the original coverage.
