# T-5140: Four Watchtower pages render with an empty site nav on a full load (/bvp, /reviewer/audit, /reviewer/overrides, /escalation-drift): render_template skips render_page's nav_groups

## Context

<!-- All four parts are required before source edits (T-4907). Plain language; link design docs for substantial tasks. -->
**Background / trigger:** 2026-11-15, while gathering the click-through evidence the independent reviewer asked for on T-5130, a full load of `/bvp` showed the site-nav bar with none of its four groups (Work, Knowledge, Architecture, Govern), so a user who lands there cannot navigate on. `/terminal` and `/fabric` show all four.

**Problem / hypothesis:** four blueprints render templates that extend `base.html` through Flask's `render_template` instead of `web.shared.render_page`: `/bvp`, `/reviewer/audit`, `/reviewer/overrides` and `/escalation-drift`. Only `render_page` supplies `nav_groups`, so `base.html`'s nav loop has nothing to draw. Before T-5130, reaching `/bvp` in the app was an htmx swap that kept the previous page's nav, so nobody saw it. T-5130 made it a full load.

**Goal:** every page that extends `base.html` draws the full site nav, however it is rendered.

**Expected outcome:** a direct or in-app full load of any of the four pages shows all four nav groups, like `/fabric`.

## RCA

**Cause:** `base.html` draws the site nav from `nav_groups`, which only `web.shared.render_page` puts in the template context. Four views render a `base.html` template with Flask's `render_template`, so their nav loop had nothing to draw: `bvp.bvp_scatter`, `reviewer.reviewer_audit`, `reviewer.reviewer_overrides` and `escalation.escalation_drift`.

**Why it went unnoticed:** inside the app these pages were reached by an htmx swap of `#content`, which kept the previous page's nav on screen. Only a direct full load showed the empty bar. T-5130 made in-app navigation to `/bvp` a full load, which exposed it. It was found while capturing the click-through the independent reviewer asked for on T-5130.

**Fix:** a context processor supplies `nav_groups` and `nav_items` to every template; a view's own value still wins. The regression test fails on the four pages without it.
