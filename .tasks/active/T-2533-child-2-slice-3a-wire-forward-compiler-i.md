# T-2533: Child-2 slice 3a: wire forward compiler into fw bpmn compile CLI verb

## Context

Slice 3a of the Child-2 forward compiler. Slices 1 (T-2531) + 2 (T-2532) shipped `tools/bpmn_to_tasks.py`
as a standalone script. This slice makes it a first-class framework verb — `fw bpmn compile <file>` —
following the same delegation pattern as `fw fabric` / `fw designer` (`bin/fw` case → `agents/<name>/<name>.sh`).

This is the integration payoff: the compiler becomes discoverable and usable through the single `fw`
entry point instead of a raw `python3 tools/...` invocation. No compiler-logic change — pure wiring +
an agent wrapper + AGENT.md. Gateway *semantics* (slice 3, G-3 inception) stay blocked on 832's
`aef:scopeOf` serialization answer (rail offset 30, Q1-Q3).
