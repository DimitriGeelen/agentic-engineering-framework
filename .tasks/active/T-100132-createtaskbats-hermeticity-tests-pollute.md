# T-100132: create_task.bats hermeticity: tests pollute live focus.yaml and fail under CLAUDECODE=1 agent sessions

## Context

Two hermeticity leaks in tests/unit/create_task.bats, both hit live during T-100130's session. (1) Focus pollution: the "--start flag" test invokes create-task.sh with PROJECT_ROOT=$FRAMEWORK_ROOT, so the T-297 focus hook (create-task.sh:466 → context.sh focus) writes T-001 into the LIVE .context/working/focus.yaml — clobbered the running session's focus 3x (check-active-task then blocks with "Task T-001 is not active"). (2) CLAUDECODE leak: the 4 inception tests fail when the suite runs inside an agent session because the T-2207 recommendation gate sees CLAUDECODE=1; they pass in a neutral shell. Related class: L-490 (FW_HERMETIC), OBS-080 (worktree gate env).

## RCA

**Symptom:** Running tests/unit/create_task.bats from inside an agent session (a) clobbered the live session's focus.yaml to T-001 — three subsequent tool calls were blocked by check-active-task with "Task T-001 is not active" — and (b) failed 4 inception tests that pass in a neutral shell.

**Root cause:** (a) setup() exported PROJECT_ROOT=$FRAMEWORK_ROOT but not CONTEXT_DIR, so the --start test's focus hook (create-task.sh T-297 → context.sh focus) resolved CONTEXT_DIR to the live project's .context and wrote the sandbox task id into the running session's working memory. (b) setup() didn't neutralize CLAUDECODE, so the T-2207 inception recommendation gate (keyed on CLAUDECODE=1) fired inside the tests.

**Why structurally allowed:** Test isolation covered TASKS_DIR only — the .context write surface added later (T-297 focus hook, T-2207 gate) was never added to the fixture's isolation set. Same class as L-490 (FW_HERMETIC) and OBS-080: env-dependent behavior leaking between live sessions and test fixtures.

**Prevention:** setup() now exports CONTEXT_DIR into the sandbox and unsets CLAUDECODE; Verification pins that a full suite run leaves the live focus.yaml byte-identical. Gate behavior remains covered by create_task_inception_recommendation_gate.bats which sets CLAUDECODE explicitly per test.
