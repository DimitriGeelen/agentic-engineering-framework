# T-2317: fix observe.sh:132 triage regex split (root-level dash, post-T-2316)

## Context

Follow-on from T-2316. `observe.sh:132` uses `re.split(r'\n  - ', content)` to split observation blocks. The 2-space dash matched the OLD heredoc indentation. T-2316 fixed the heredoc to emit root-level dash (`\n- `) — but left the triage display reader on the old pattern. Symptom: `fw note triage` displays mismatched id↔text pairs (regex matches `tags:\n  - <tag>` boundaries instead of observation boundaries, so the splitter picks up tag-list items as OBS-id candidates).

Replace the regex with `yaml.safe_load` — same library round-trip the T-2316 regression already validates. One Python block, simpler than a regex catalog.
