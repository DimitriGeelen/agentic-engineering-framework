## Decisions

### 2026-07-28 — Subprocess isolation over in-process reload
- **Chose:** boot the app in a subprocess with PROJECT_ROOT env pointing at a synthetic consumer.
- **Why:** in-process reload of web.shared under a foreign root is the documented OBS-094 tarpit — module-level constants leak into every later test; subprocess sidesteps module identity entirely.
- **Rejected:** conftest-style pop-and-reimport of the web.* namespace.

### 2026-07-28 — Negative-check findings (two course corrections during build)
- **Finding 1 (coverage hole):** first negative run stayed GREEN — the G-004 import is LAZY inside /review/<task_id>'s handler, and the parameterless sweep skips parameterized routes. Fix: seed T-9999 in the consumer skeleton + curated probes (/review, /tasks, /inception) so the lazy paths execute.
- **Finding 2 (sys.path masking):** second negative run STILL green with only review.py broken — sys.path is process-global, so approvals.py's correct insert covers review.py's broken one. The faithful G-004 reproduction (all three sites broken, the actual origin state) reds correctly on ModuleNotFoundError: dispatch_pause. Limit documented in the test docstring: single-site regressions are the T-2648 grep-lint's layer; this smoke owns whole-class and request-time shapes (relative_to, subprocess paths, templates).
