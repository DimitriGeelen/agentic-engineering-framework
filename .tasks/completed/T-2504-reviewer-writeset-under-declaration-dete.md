# T-2504: reviewer: write_set under-declaration detector (IW-4)

## Context

IW-4 from T-2324 (GO 2026-06-26): add a reviewer static-scan detector that flags when a
task declares `write_set:` but the body references file paths not covered by any declared glob.
Under-declaration is the dangerous error (unchecked parallel dispatch collision); over-declaration
is safe and must NOT be flagged.

Detector lives in `lib/reviewer/static_scan.py`. Unit tests in
`tests/unit/test_reviewer_write_set_underdeclared.py`.

## Acceptance Criteria

### Agent
- [x] `detect_write_set_underdeclared` function added to `lib/reviewer/static_scan.py` and
      called in `scan_task()` after the existing detectors.
- [x] Under-declared case (write_set declared, body references uncovered path in a known source dir
      with write context) → finding emitted with `pattern_id="write-set-underdeclared"`,
      `lie_severity="partial"` (CONCERN not FAIL).
- [x] Fully-declared case (every body-referenced path covered by a write_set glob) → no finding.
- [x] Missing write_set (field absent or null) → no finding (nothing declared, nothing to under-declare).
- [x] Unit tests in `tests/unit/test_reviewer_write_set_underdeclared.py` pass: both positive
      and negative cases covered.
- [x] `bin/fw test unit` passes (or `pytest tests/unit/test_reviewer_write_set_underdeclared.py` passes).
