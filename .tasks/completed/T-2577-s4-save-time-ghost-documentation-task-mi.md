# T-2577: S4 save-time ghost documentation-task minting via FW_TASK_ORIGIN gate (T-2571)

## Context

T-2571 GO slice S4 (design axis C1, ratified): first sighting of a ghost at
`/api/save` mints a documentation task through the gated writer
(`fw task create` + `FW_TASK_ORIGIN=designer-ghost`), so the parallel
"document the workflow" task from the operator's original sketch exists the
moment the forward-reference is drawn. Gate — not caller — enforces
owner:human + captured (T-2543 pattern); horizon:later so minting never
steals focus (T-100146 class). Idempotent per uuid: the ghost's `task` field
stores the T-ID; a re-save/re-sighting never double-mints. Design doc:
docs/reports/T-2571-offpage-connector-linkage.md (§C, §S4).
