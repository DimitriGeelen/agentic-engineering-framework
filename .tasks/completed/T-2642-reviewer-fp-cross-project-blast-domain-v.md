## RCA

**Symptom:** 832's foreign-corpus sweep (their T-262) reported a confirmed
FP: the Layer-1 `cross-project-blast` escalation trigger — the sweep's only
needs-human — fired on their T-115, a pure SVG-layout task, via the phrase
"clusters all nodes into columns" where "nodes" means diagram nodes.

**Root cause:** the ac_text pattern's `all\s+(machines|hosts|nodes)`
alternative treated "all nodes" as unconditionally fleet vocabulary. "nodes"
is heavily overloaded (SVG nodes, graph nodes, DOM nodes, BPMN nodes); the
pattern had no context requirement to disambiguate.

**Why structurally allowed:** the trigger vocabulary was written against
AEF's corpus where "all nodes" reliably meant proxmox/cluster hosts; no
diagram-editing corpus had ever been scanned. Escalation patterns are single
regexes with no co-occurrence machinery, so ambiguity had nowhere to go.

**Prevention:** 832's verbatim T-115 sentence is pinned as a negative
fixture (it even contains the verb "clusters" — which is why the
co-occurrence set uses singular-only "cluster"), plus a positive
infra-co-occurrence guard and an unambiguous-forms guard in
tests/unit/test_reviewer_static_scan.py — the tests load the REAL catalogue
file, so any future re-widening of the pattern fails the suite.
