## RCA

**Symptom:** At critical budget level, `budget-gate.sh` allows `git commit`/`git add`
and `fw handover` but the resulting commits never reach `origin` — the session can
wrap up and commit but has no allowed path to push, stranding work locally. Hit
twice on 2026-07-21 (handover commits including `beae6eeac` never landed until a
subsequent session pushed them manually).

**Root cause:** The critical-level allow-list regex in `budget-gate.sh`
(`is_allowed_cmd`, line ~150) enumerated `git commit|git add|git (status|log|diff)`
and a set of `fw ...` subcommands, but never included `git push` or `git fetch`.
"Landing" (push) was structurally conflated with "committing" — the allow-list
author covered the local half of wrap-up but not the half that actually delivers
the work to the shared branch. `fw handover --commit` internally shells out to
`git push` for the auto-push step (T-1144), but at critical that inner `git push`
call is itself gated by the same PreToolUse hook and was blocked — so even the
"handover pushes automatically" path silently failed to land.

**Why structurally allowed:** No test asserted `git push`/`git fetch` at critical.
The existing bats suite (`tests/integration/budget_gate.bats`) had "allows git
commit via Bash" and "allows fw handover via Bash" tests but nothing covering the
push leg, so the gap shipped and stayed invisible through every prior review of
this file. Sibling class to T-2054/T-2462 (push previously missing from the
active-task Write/Edit gate, fixed there but not mirrored into budget-gate.sh's
separate allow-list).

**Prevention:** `agents/context/budget-gate.sh` critical allow-list regex now
includes `git\s+push|git\s+fetch`. Two new bats tests
(`T-2587: fast path critical: allows git push via Bash`,
`T-2587: fast path critical: allows git fetch via Bash`) pin the allowed path;
a third (`source-file Write still blocked`) pins that this doesn't loosen the
gate for actual new work. Block-message stderr text ("ALLOWED"/"BLOCKED" lines)
updated to name push explicitly so the agent doesn't have to guess.
