# T-4345 — v1.8.12 security hotfix

Operator yes 2026-10-19 ("yes, go ahead with the v1.8.12 hotfix"). Lane as v1.8.10 (docs/reports/T-4092-hotfix-v1810.md).

## Why

ring20-dashboard reported two security regressions in released v1.8.11 (msg 4699f56c), both reproduced here:
1. **T-4343** — the read-only allowlist (agents/context/lib/safe-commands.sh, from T-4264) treated `git -C DIR`,
   `--git-dir=X` and `--work-tree=X` as read-only for repositories OUTSIDE the project, whose config
   (core.fsmonitor, core.pager, diff.external, filters) can run arbitrary commands.
2. **T-4344** — the boundary read scanner (lib/shell_write_scan.py, from T-4284) skipped the word after flags that
   take no value, hiding outside reads (`git diff --no-index -m /etc/shadow`, `git log --summary /etc/shadow`).
