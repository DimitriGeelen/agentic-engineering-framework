How to override

Set FW_* environment variables before starting the framework. Resolution order: explicit CLI flag > env var > default.

# Per-session
export FW_CONTEXT_WINDOW=1000000

# In systemd service (persistent)
Environment=FW_PORT=5050

# In .bashrc (persistent)
export FW_DISPATCH_LIMIT=5

Run fw doctor to validate overrides and check for out-of-range values.
