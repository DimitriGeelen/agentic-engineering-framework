## Criterion

A task in `.tasks/active/` qualifies when: frontmatter `status:` is
`started-work` or `issues`; the Acceptance Criteria section has at least
one Agent AC; every Agent AC is ticked `- [x]`; zero Human AC checkboxes
are left unticked. Lines inside HTML comment blocks (including the task
template's own example ACs) are excluded, so an unedited template never
self-qualifies.

## Limits — read before acting on this list

**A ticked box is a claim, not evidence.** This scan reads checkbox
characters; it does not run the task's `## Verification` block, does not
re-derive whether the described work actually shipped, and cannot tell a
genuinely finished task from one where an agent ticked ahead of itself.
Each row below is a **candidate for close, never a closure** — verify with
`fw task verify T-XXX` or a per-task review before touching
`fw task update --status work-completed`. Never batch-close on this list
alone (CLAUDE.md Human Task Completion Rule).

Rows with an empty `## Verification` block need that scrutiny most —
nothing mechanical would gate their close.
