# The shape of the fix

Split `$COMMAND` into segments on `;`, `&&`, `||`, `|` and newline. A segment is
exempt if its **command position** is termlink — first word, or first word after a
wrapper (`sudo`, `env VAR=v`, `timeout N`, `nohup`). Non-exempt segments are
re-joined and handed to the existing Python boundary analysis unchanged.

Splitting must not split inside quotes. The file already has `_strip_quoted()`
(line ~160, T-1361/G-053-C) which walks char-by-char tracking quote state and
preserves lengths — reuse that machinery to find safe split points rather than
writing a second quote-aware walker. **A second definition of the same rule is
exactly what the framework opens tasks to remove.** If the existing helper cannot
be reused as-is, say so in your bus post with the reason; do not silently fork it.
